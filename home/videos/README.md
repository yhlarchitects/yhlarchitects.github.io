# Background films

Add each finished video as a lowercase, hyphenated MP4 filename in this folder. Keep its audio track. The existing build automatically includes all MP4 files. An optional first-frame WebP poster can share the same basename.

The home page immediately attempts playback with sound. If autoplay with sound is blocked, video playback continues muted until the first click or touch anywhere on the page. YHLA opens the contact text and applies depth-four blur. Selecting YHLA again or pressing Escape closes the text without changing the sound. Each film loops. On refresh, the previous film is excluded when at least two films are available. With one film, the same film repeats.

The lettering is outlined from the existing Univers LT Std 55 Roman font at the same em size for all three lines. The font file is not uploaded.
